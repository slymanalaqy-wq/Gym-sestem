# Gym Management System
A professional web-based application built with **Native PHP** and **MySQL** to manage sports club operations.

## Key Features:
* **Member Management:** Register, update, and track club subscribers easily.
* **Financial Tracking:** Manage subscription fees, payments, and generate financial reports.
* **Attendance System:** Support for automated attendance tracking (including biometric/fingerprint integration).
* **Dashboard:** A simple and intuitive interface for daily statistics and overview.

## Technical Details:
* **Backend:** Clean and secure Native PHP code.
* **Database:** Optimized MySQL relational database.
* **Frontend:** Responsive design using HTML, CSS, and JavaScript.

## How to Run:
1. Import the provided `.sql` file into your MySQL database.
2. Configure your database connection in the config file.
3. Run the project on a local server (like XAMPP or Laragon).
